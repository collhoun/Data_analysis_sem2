# Отчёт по лабораторной работе №1: Анализ данных и построение моделей машинного обучения

---

## 1. Описание данных

**Датасет:** `student_lifestyle_100k.csv` — 100 000 записей о студентах.

**Признаки:**

| Признак | Тип | Описание |
|---|---|---|
| Student_ID | int64 | Уникальный идентификатор |
| Age | int64 | Возраст (18–24) |
| Gender | str | Пол (Male/Female) |
| Department | str | Факультет |
| CGPA (Academic_score) | float64 | Средний балл (1.56–4.00) |
| Sleep_Duration | float64 | Продолжительность сна, ч (3–12) |
| Study_Hours | float64 | Часы учёбы (0–12.8) |
| Social_Media_Hours | float64 | Часы в соцсетях (0–10) |
| Physical_Activity | int64 | Физическая активность, мин (0–149) |
| Stress_Level | int64 | Уровень стресса (2–10) |
| Depression | bool | Наличие депрессии |

## 2. Разведочный анализ данных (EDA)

### 2.1 Описательная статистика

- **Age** — равномерное распределение от 18 до 24 лет (среднее ≈ 21)
- **Academic_score** — близко к нормальному, среднее ≈ 2.90
- **Sleep_Duration** — нормальное распределение, пик около 7 часов
- **Study_Hours** — нормальное, среднее ≈ 4.5 часов
- **Social_Media_Hours** — лёгкий правый хвост, большинство 2–5 часов
- **Physical_Activity** — бимодальное распределение (пики около 0 и 150 мин)
- **Stress_Level** — ближе к равномерному (2–10)
- **Depression** — сильный дисбаланс: ~90% без депрессии, ~10% — с депрессией

### 2.2 Дубликаты и пропуски

- Дубликатов не обнаружено (100 000 → 100 000)
- Пропусков нет во всех 11 столбцах

### 2.3 Выбросы и аномалии

- Выявлены **478 записей**, у которых сумма `Sleep_Duration + Study_Hours + Social_Media_Hours + Physical_Activity/60 > 24` часов — физически невозможные данные
- После очистки: **99 522 записи**

### 2.4 Предобработка

- **Gender** → бинарное кодирование: Male = 1, Female = 0
- **Department** → One-Hot Encoding (4 бинарных признака: Business, Engineering, Medical, Science)
- **Physical_Activity** → нормировка: деление на 60 (перевод в часы)
- **Depression** → преобразование bool → int (0/1)

### 2.5 Корреляционный анализ

Ключевые наблюдения из матрицы корреляций:
- **Study_Hours** имеет слабую положительную корреляцию с **Academic_score**
- **Depression** положительно коррелирует со **Stress_Level**
- **Sleep_Duration** слабо отрицательно коррелирует с **Depression**

|---|---|---|---|---|---|

### 3.4 Выводы по линейной регрессии

1. **Крайне низкий R²** (0.018–0.025) — поведенческие признаки объясняют лишь ~2% дисперсии академической успеваемости
2. **Dataset 3** с инженерными признаками показал лучшее качество (R² = 0.025 на test), что подтверждает полезность созданных фичей
3. **CatBoost** улучшил R² до 0.046 (~60% прирост относительно линейной модели), но качество всё ещё низкое

5. **Главный вывод:** CGPA определяется факторами, не представленными в данных (интеллект, мотивация, качество преподавания и т.д.)

## 4. Логистическая регрессия — классификация депрессии

### 4.1 Метрики классификации

| Метрика | Train | Validation | Test |
|---|---|---|---|
| **Accuracy** | 0.6233 | 0.6220 | 0.6160 |
| **Precision** | 0.1669 | 0.1674 | 0.1626 |
| **Recall** | 0.6844 | 0.6943 | 0.6882 |
| **F1-Score** | 0.2683 | 0.2698 | 0.2630 |
| **AUC-ROC** | 0.6852 | 0.6925 | 0.6857 |

### 4.2 Анализ результатов

- **Accuracy ≈ 62%** — выше случайного угадывания (50%), но модель часто ошибается
- **Precision ≈ 16%** — из всех предсказанных случаев депрессии лишь 16% верны (много ложных срабатываний)
- **Recall ≈ 69%** — модель находит ~69% реальных случаев депрессии
- **AUC-ROC ≈ 0.69** — умеренная разделяющая способность
- **Низкий F1 (0.26)** — следствие сильного дисбаланса классов (90/10)

### 4.3 Важнейшие признаки (коэффициенты модели)

Наибольшее влияние на прогноз депрессии оказывают:
1. **Stress_Level** — самый значимый положительный предиктор (чем выше стресс, тем выше риск депрессии)
2. **Academic_score** — отрицательный коэффициент (более низкий CGPA ассоциирован с депрессией)
3. **Sleep_Duration** — отрицательный коэффициент (меньше сна → выше риск)

### 4.4 Проверка на переобучение

Learning curve показывает:
- Training score и Cross-validation score сходятся с ростом объёма данных
- Разрыв между Train и Test метриками минимален (Accuracy: 0.623 vs 0.616)
- **Модель не переобучена** — кривые обучения сходятся, метрики на всех выборках сопоставимы

## 5. Общие выводы

1. **Линейная регрессия** для прогнозирования CGPA показала неудовлетворительное качество (R² < 0.05). Поведенческие паттерны (сон, учёба, соцсети) слабо объясняют академическую успеваемость.

2. **Логистическая регрессия** для предсказания депрессии показала умеренное качество (AUC-ROC ≈ 0.69). Модель хорошо выявляет реальные случаи (Recall ≈ 69%), но даёт много ложных срабатываний (Precision ≈ 16%).

3. **Дисбаланс классов** в задаче депрессии (90/10) — основная проблема, требующая техник вроде SMOTE или изменения порога классификации.

4. **Отсутствие переобучения** подтверждено как для линейной регрессии, так и для логистической — метрики на train/validation/test выборках стабильны.

5. Для улучшения качества моделей необходимы **дополнительные признаки**: мотивация, качество сна, социальные связи, финансовое положение, качество преподавания и т.д.
